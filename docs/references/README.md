# Research References

This folder contains repository-safe research summaries for source feeds and export targets.

The project intentionally does not commit:

- raw distributor inventory files
- dealer credentials
- full downloaded copies of vendor or platform web pages
- product images

Reference summaries should include:

- source URLs
- date reviewed
- relevant findings
- implementation implications
