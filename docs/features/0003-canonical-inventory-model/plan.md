## Locked Decisions

- GoDaddy `PRODUCT ID` is owned by GoDaddy and must not be generated by this tool.
- New-import mode is the default GoDaddy export mode and leaves `PRODUCT ID` blank.
- Update mode should be supported later, but only when known GoDaddy product ID mappings exist.
- SQLite should be added as the local store for export history and GoDaddy product ID mappings.
- The model should split distributor rows into `SourceOffer` and grouped sellable products into `CanonicalProduct`.
- The same UPC appearing in multiple feeds should produce one canonical product with multiple offers, not multiple GoDaddy products by default.
- Use UPC-based canonical SKUs when UPC is present, such as `UPC-736676037018`, because this is the safest default for avoiding duplicate website products across distributors.
- Source selection should eventually be configurable and should preserve all candidate offers.
- If update mode lacks mappings, the UI should guide the user to sync a GoDaddy export file.
- Run-level business behavior belongs in `RunConfiguration` and policy objects, not in feed adapters.
- Pricing is configurable. The current 25 percent markup is only the initial default pricing profile, not a fixed rule.
- Preserve extra source fields in `attributes: dict[str, str]` or equivalent key/value metadata when there is no first-class model field.
- Initial pricing uses configured markup from distributor cost. If MAP is present and higher than the markup price, use MAP. If MAP is absent, use the configured markup price and do not try to infer MAP.
- Distributor sale pricing is ignored initially unless a later feature explicitly enables it.
- Dropshipping is out of scope for the MVP; `CANDROPSHIP` should be preserved only as source metadata for now.
- Lipseys image URLs can be built from `IMAGENAME` with `https://www.lipseyscloud.com/images/{IMAGENAME}?height=320&width=480&scale=canvas`.
- Current Davidsons sample feeds have no image fields; leave Davidsons image URLs blank unless a future source provides image data.
- Allocated inventory is not exportable by default. This includes Lipseys `ALLOCATED` offers and Davidsons `A` / `A*` quantity tokens.
- `99+` inventory is exportable by default as an approximate available quantity of `99`, with a warning. Other `X+` values use `X` as the lower bound unless explicitly configured otherwise.
- GoDaddy supports inventory and backorder controls, but the MVP should not export allocated/unknown inventory as inquiry-only products because no safe CSV-supported "call for details" state has been confirmed.
- FFL/SOT/NFA flags should be exported as description notes initially, not excluded by default.
- Preserve categories/families in the middle model, but do not make GoDaddy storefront category assignment part of the first import.
- Missing or broken image URLs should warn only and should not block otherwise valid product rows.
