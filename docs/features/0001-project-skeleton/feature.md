# Project Skeleton

## Purpose

Create the initial repository structure for Inventory Feed Tool so future ETL features can be developed, documented, tested, and packaged consistently.

## Scope

- Root README and changelog.
- Python package skeleton.
- Hello-world command-line entry point.
- Basic automated test.
- GitHub Actions test workflow.
- Feature documentation folder structure.

## Out of Scope

- Distributor feed parsing.
- GoDaddy CSV export.
- Desktop UI.
- Windows executable packaging.

Those will be handled as separate features.
